# adaptable_business
This repository contains the main code for the manuscript "Creating adaptable small businesses: a mixed integer approach for modeling restaurants’ resilience tactics in the face of disruptions". FB_v4_restored_from_takeout.py contains everything needed to build the model, run the optimization, and visualize the results. The model is built using the Gurobi optimization library and the code is written in Python.

The ideal environment to run the code is UW ThinkLab's office server.
